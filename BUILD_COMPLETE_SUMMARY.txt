ITEM 2: AUDIT LOG ✅
──────────────────────
What it does:    Logs every alert generation with full decision trail
Timestamp:       ISO format (2026-09-12T14:35:42Z)
Data Tracking:   Which CSV/XLSX files were used and their dates
Decision Log:    For each SKU: MOS value, threshold, why included/excluded
Manual Changes:  Logs when Michael adds/removes SKUs and reason
Archive:         52-week retention (1 year of complete history)

Example Log Entry:
  {
    "timestamp": "2026-09-12T14:35:42Z",
    "factory": "AIM",
    "summary": { "totalSkusOnAlert": 42 },
    "decisions": {
      "included": [
        { "sku": "818244", "mos": 0.636, "threshold": 1.5 }
      ]
    }
  }

API Endpoints:
  POST /api/audit-log?action=log          → Create log entry
  GET  /api/audit-log?action=history      → Read past entries
  GET  /api/audit-log?action=comparison   → Week-over-week comparison
  POST /api/audit-log?action=update       → Mark approved/sent

Files Created:
  → /api/audit-log.js (Vercel endpoint + file storage)

Status:  ✓ Ready to be called from alert generation
